# Physics Lab · 跨学科计算物理实验平台

一个单文件（零依赖、纯 HTML + JS）的交互式计算物理实验室：打开 `index.html` 即可在浏览器本地运行全部实验，所有数值均为本机实时计算。

> Open `index.html` in a browser — no build step, no dependencies. All 18 modules run locally, with verification tables computed live.

### 数值验证
- 步长收敛性（h, h/2, h/4, h/8 对 h/32 参考解）、误差阶、能量漂移
- 单摆 RK4 默认 h=0.01：误差 1.2e-7 → 2.9e-11，阶 3.98/3.99/4.00

### 真实 3D 引擎
- 自研 Canvas 透视投影（未用 Three.js）：Vec3 + 旋转矩阵、拖动旋转、滚轮缩放
- 速度 Verlet 粒子系统、3D 矢量场、参数曲面三角网格（Flamm / 抛物面 / 波面 / 鞍面）

### 广义相对论求解器
- Schwarzschild 度规（G=c=1）：数值微分求 Christoffel、Riemann、Ricci、Kretschmann
- Christoffel 与解析最大差 2.6e-11；真空 Ricci 最大 6.7e-9；测地线 8 维 RK4（r₀=10 束缚偏心轨道）

### 分析力学（第 1 阶段）
- 拉格朗日 / 哈密顿方程、辛积分器对照（Euler / 辛 Euler / Verlet / RK4 / 隐式中点）、双摆混沌与 Lyapunov 指数 λ≈1.1/s

### 麦克斯韦方程组 + FDTD（第 2 阶段）
- Yee 交错网格 1D/2D、Poynting 矢量、能量密度、PEC 边界
- 脉冲速度 v/c=1.0000；ε=4 介质板反射 −0.343（解析 −1/3）、透射 0.640（解析 2/3）；2D ∇·B 残差 5.3e-16；Courant 数 S=1.2 失稳、S=0.5 稳定

### 量子力学（第 4 阶段）
- 1D 含时薛定谔方程，Crank–Nicolson + Thomas 追赶法（ħ=m=1）：自由波包、谐振子相干态与 n=1 本征态、矩形势垒隧穿、双高斯干涉
- 模 T=2 时 1.000000；σ(2)=1.405（解析 1.414）；HO n=1 能量 1.499（解析 1.5）；隧穿透射 0.240（平面波解析 0.245，波包能量展宽所致）

### 混沌动力学
- Lorenz 吸引子：分离拟合 λ≈0.81/s（文献长期值 0.905，有限时间估计在 0.7–0.9 间浮动）

### 流体力学
- 不可压 Navier–Stokes，涡量–流函数法，Jacobi 迭代解泊松方程
- Taylor–Green 涡 ν=0.1：E/E₀ 实测 0.691 / 0.463 / 0.139（t=1/2/5，解析 0.670 / 0.449 / 0.135）

### 连续介质力学
- 1D 弹性杆有限元（线性元刚度矩阵 + Thomas 求解）
- f=sin πx 时 N=8/16/32/64 误差 4.1e-3 / 1.0e-3 / 2.6e-4 / 6.4e-5，误差阶恰好 2.00

### 热力学与统计物理
- 热传导显式差分（Dirichlet 边界）：热模 t=10 振幅 0.373（与解析相同）
- 2D 理想气体硬盘分子动力学：⟨v²⟩≈2.0、平均速率≈1.26（Maxwell–Boltzmann 解析 1.253）

### 数学物理
- 基 2 FFT：Parseval 比 1.0000、高斯 Fourier 变换相对误差 5.8e-7、方波 Gibbs 过冲 1.179

### 天体物理
- Plummer 球 N 体引力，Leapfrog 辛积分：能量漂移 1.7e-5、位力比 0.996、旋转曲线、引力透镜偏折 α=4GM/c²b

## 使用

直接用浏览器打开 `index.html`（或 `PhysicsLab.html`，两者内容相同）。左侧选模块，右侧调参数，每个模块都带「运行验证」按钮和对照表。

## 说明

- 全部计算在本地浏览器完成，不联网、不依赖外部库。
- 各模块页内注有预验算数值与适用条件；与解析值有偏差处均已注明原因（如波包能量展宽、有限粒子数统计涨落、数值黏性）。
